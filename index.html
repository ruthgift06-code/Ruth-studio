Good to know

Frequently asked questions

Do you work with clients in any country?

Yes — bookings, briefs and delivery are all handled online, so location and timezone never limit a project.

What file formats do I receive?

Every project ships with editable source files plus export packs sized for print, web and social, so nothing extra needs to be requested.

How many revisions are included?

Single projects include two rounds; the full brand build includes three. Additional rounds can be added at booking.

Can I reschedule a booked slot?

Yes, up to 24 hours before the confirmed time, directly from the confirmation email.
